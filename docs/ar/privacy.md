# خصوصيتك عند تجربة «منهاجنا»

[التحميل والتجربة](https://djazair.dev/ar/minhajna/) · [السياسة الكاملة بالإنجليزية](../../PRIVACY.md)

هذا الملخّص يخص النسخة التجريبية 0.1.0.

## على هاتفك

تُحفظ سجلات الأقسام والحصص والدروس والمناداة مشفّرة على هاتفك. اسمك اختياري.

**استعمل القسم التجريبي أو أسماء للتجربة فقط، لا بيانات تلاميذك الحقيقية.**

لا تحتاج إلى حساب. يعمل التطبيق دون إنترنت، ولا يرسل سجلاتك إلى المشروع. لا إعلانات أو تتبّع أو تقارير تلقائية.

إذا اخترت فتح رابط كود التطبيق، يطلب موافقتك قبل فتح المتصفح. لا يرسل التطبيق سجلاتك أو معلومات تعرّف بك مع الرابط.

## إذا حذفت التطبيق أو فقدت الهاتف

**لا توجد نسخة احتياطية أو إمكانية لاسترجاع ما تفقده.** ولا تشمل النسخ الاحتياطية السحابية للهاتف سجلات التطبيق.

حذف التطبيق أو مسح بياناته أو فقدان الهاتف قد يفقدك ما سجّلته، ولا نستطيع استعادته. واصل استعمال دفاترك الرسمية.

## رسائلك وحقوقك

للملاحظات: [فيسبوك](https://www.facebook.com/djazairdev)، أو البريد [contact@djazair.dev](mailto:contact@djazair.dev)، أو GitHub اختيارياً. يستخدم مسؤول المشروع رسالتك وبيانات التواصل للرد عليك.

تُحفظ رسالتك لدى الخدمة التي تختارها، ولكل خدمة قواعدها للاحتفاظ بالرسائل. يمكنك طلب حذف الرسائل التي يحتفظ بها المشروع.

- للاطّلاع على معلومات تخصك أو تصحيحها أو حذفها، راسل البريد نفسه بشكل خاص.
- بيانات التواصل لتنظيم التجربة لدى مسؤول المشروع فقط. لا تُنشر، وتُحذف متى طلبت ذلك.

منشورات GitHub والتعليقات العلنية يقرؤها الآخرون. لا ترسل بيانات تلاميذ حقيقيين عبر أي قناة، حتى بشكل خاص. صور الشاشة من القسم التجريبي فقط، دون معلومات شخصية أو صور أشخاص.

لمشكلة أمن أو خصوصية، [راسلنا بالبريد بشكل خاص](mailto:contact@djazair.dev?subject=Minhajna%20private%20report). [طريقة الإبلاغ](../../SECURITY.md).

بيانات التلاميذ لا تصل إلى المشروع، والملاحظات الخاصة لا تغادر أجهزة الأستاذ.
