# دليل الصياغة العربية للمساهمين

هذا الدليل للمساهمين الذين يكتبون واجهة التطبيق وأدلّته. نستعمل أسماء الوثائق المتداولة في المدرسة الجزائرية، ونشرح ما يفعله الأستاذ بعبارات مباشرة.

## تعريف المشروع

«منهاجنا» مشروع مجاني ومفتوح المصدر لبناء نظام رقمي متكامل لمنظومة التعليم في الجزائر. بدأنا برقمنة الكراس اليومي ودفتر النصوص وكراس المناداة، ونطوّره تدريجيًا ليشمل بقية الأعمال التربوية والإدارية.

هذا التعريف يصف رؤية المشروع، ولا يعني أن النظام مكتمل أو معتمد رسميًا. الميزات المتاحة موضّحة في [صفحة التحميل والتجربة](https://djazair.dev/ar/minhajna/).

## المصطلحات التربوية

| المقصود                   | الصياغة التي نستعملها                                                                                         |
| ------------------------- | ------------------------------------------------------------------------------------------------------------- |
| الجدول الأسبوعي           | جدول الحصص الأسبوعي، أو جدول التوقيت الأسبوعي. «استعمال الزمن» مستعمل أيضًا، لكنه لا يشرح الإجراء وحده        |
| ما يفعله الأستاذ بالجدول  | إدخال جدول حصصك الأسبوعي، لا «تنظيم استعمال الزمن» أو الإيحاء بإعادة توزيع حصص المؤسسة                        |
| القسم                     | القسم الذي تضمّه قائمة التلاميذ، وليس فوجًا فرعيًا                                                            |
| تقسيم القسم لبعض الحصص    | الأفواج الفرعية؛ يُشرح المقصود عند أول استعمال                                                                |
| الحصص المتكررة كل أسبوعين | الحصص التي تتكرر كل أسبوعين، لا «الأسابيع المتناوبة» دون شرح                                                  |
| الوثيقة السنوية المرجعية  | المخطط السنوي أو التدرج السنوي، بحسب عنوان الوثيقة والطور والمادة؛ ليست كل المخططات رسمية أو متاحة في التطبيق |
| التحضير اليومي            | الكراس اليومي: ما يُحضَّر للتدريس                                                                             |
| توثيق ما دُرّس            | دفتر النصوص: ما أُنجز فعلًا؛ لا يُعدّ الدرس المقترح درسًا منجزًا دون تسجيل الأستاذ                            |
| تسجيل إنجاز درس           | سجّل الدرس الذي قدّمته                                                                                        |
| تصحيح التسجيل             | عدّل ما سجّلته؛ لا «صحّح الدرس» التي قد تُفهم على أنها تصحيح تمرين                                            |
| متابعة تنفيذ المخطط       | متابعة الدروس المنجزة في كل قسم، لا «تقدّم الأقسام» التي قد تُفهم على أنها نتائج التلاميذ                     |
| المناداة                  | تسجيل الحضور والغيابات والتأخرات. نستخدم «كراس المناداة» في تعريف المشروع                                     |
| أماكن التلاميذ            | مخطط أماكن جلوس التلاميذ                                                                                      |
| التنقيط                   | تسجيل النقاط وحساب المعدلات. دفتر التنقيط ليس كراس المناداة                                                   |
| ابتدائي، متوسط، ثانوي     | الطور التعليمي، لا المستوى الدراسي                                                                            |
| السنة الأولى متوسط مثلًا  | المستوى الدراسي                                                                                               |
| 2026–2027 مثلًا           | السنة الدراسية                                                                                                |

لا نستبدل أسماء الهيئات أو الأدوار القانونية لمجرد تبسيط النص: مجلس التعليم ليس مجلس القسم، والمدير والمفتش والسلطة المخوّلة بالاطّلاع أدوار مختلفة. لا تتغيّر صلاحياتهم بتغيير الصياغة.

## المصطلحات التقنية

هذه بدائل للشرح اليومي. أمّا تعريف المشروع والتزاماته، فنستعمل لهما النص المعتمد في [README.md](../../README.md).

| المصطلح          | صياغة أبسط                                                                |
| ---------------- | ------------------------------------------------------------------------- |
| مدخلاتك          | ما سجّلته                                                                 |
| طراز الهاتف      | نوع الهاتف                                                                |
| تصدير الدفاتر    | حفظ الدفاتر كملفات                                                        |
| المزامنة         | استعمال نفس السجلات على أكثر من جهاز                                      |
| الشيفرة المصدرية | كود التطبيق، في المعلومات التقنية لا في دعوة التجربة                      |
| حزمة المخطط      | المخطط السنوي المتاح داخل التطبيق؛ لا يوصف بأنه رسمي إلا إذا استوفى شروطه |
| كتابة العناصر    | إدخال عناوين الدروس يدويًا                                                |
| بيانات وهمية     | أسماء ودروس للتجربة، لا بيانات تلاميذ حقيقيين                             |

حزمة المخطط نسخة مهيّأة للتطبيق، وليست أي ملف PDF. نذكر رقم نسختها ومصدرها وحالتها في المعلومات التقنية، ونميّز دائمًا بين مثال للتجربة ومخطط رسمي.

## أسماء الأزرار في الإصدار المنشور

في أدلّة النسخة 0.1.0، ننقل أسماء الأزرار كما تظهر في التطبيق:

- «دون حزمة: كتابة العناصر»: نوضّح أنه خيار إدخال عناوين الدروس يدويًا.
- «تأكيد الحصة»: نوضّح أنه تسجيل ما أُنجز، وليس إثبات حضور الأستاذ.
- «مخطط الجلوس»: نوضّح أنه يعرض أماكن جلوس التلاميذ.
- «إضافة القسم التجريبي» و«المساعدة والخصوصية»: يُنقلان كما يظهران.

مع كل إصدار جديد، نراجع أسماء الأزرار وشروحها معًا. لا نغيّر معنى الحصة أو الدرس أو السجل، ولا ننسب إلى الإصدار ميزة غير متاحة فيه.
