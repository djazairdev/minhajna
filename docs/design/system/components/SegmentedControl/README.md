# SegmentedControl

Two or three views of the same thing, such as roll call as a list or as the seating plan.

- **Provide** two or three short labels. The current segment is `board` with `chalk` text, marked `aria-current` or `aria-pressed`.
- Segments are 48px tall on phones. Web screens use 42px or 34px segments beside charts.
- **Canvas:** 63 boards, such as Roll, Roll-seats and Calendar-add.
